## 🏗️ 应用架构

### 完整的 React 单页应用（SPA）

```
CMoneySystem/
├── frontend/                      ← React 前端应用
│   ├── src/
│   │   ├── pages/                ← 5个完整页面
│   │   │   ├── HomePage.tsx      ← 首页（搜索+热门股票）
│   │   │   ├── AnalysisPage.tsx  ← 综合分析页面
│   │   │   ├── PredictionPage.tsx ← 趋势预测页面
│   │   │   ├── FactorsPage.tsx   ← 因子配置页面
│   │   │   └── HistoryPage.tsx   ← 历史记录页面

│   │   │   ├── layout/          ← 布局组件
│   │   │   │   └── MainLayout.tsx
│   │   │   └── visualization/   ← 可视化组件
│   │   │       ├── PriceChart.tsx

│   │   ├── services/            ← API服务层
```

## 🚀 如何运行

### 方式1: 开发模式（推荐开发调试）

```bash
# 1. 进入前端目录
cd /storage/emulated/0/Download/CMoney/CMoneySystem/frontend

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 访问应用
# 浏览器打开: http://localhost:5173
```

### 方式2: 生产构建（部署使用）

```bash
# 1. 构建生产版本
npm run build

# 2. 预览构建结果
npm run preview

# 构建产物在: frontend/dist/
```

### 方式3: Docker 部署（容器化）

```bash
# 1. 构建镜像
docker build -t cmoney-frontend .

# 2. 运行容器
docker run -p 5173:5173 cmoney-frontend

# 3. 使用 docker-compose
docker-compose up -d
```

### 环境变量配置

创建 `.env` 文件：

```bash
# API地址
VITE_API_URL=http://localhost:5000/api

# 应用配置
VITE_APP_TITLE=CMoney 股价预测系统
VITE_APP_VERSION=1.0.0
```
