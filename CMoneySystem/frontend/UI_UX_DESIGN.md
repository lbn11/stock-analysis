# CMoney 股价预测系统 - UI/UX 设计规范

## 设计理念

### 核心价值
- **专业性** - 金融级的专业设计
- **清晰性** - 信息层次分明，易于理解
- **高效性** - 快速获取关键信息
- **可信赖** - 数据准确，结果可靠

### 设计原则
1. **数据驱动** - 以数据展示为核心
2. **视觉层次** - 重要信息优先展示
3. **操作便捷** - 减少操作步骤
4. **反馈及时** - 实时响应用户操作

## 交互设计

### 1. 加载状态

#### 全局加载
- 页面切换时显示骨架屏
- 避免白屏闪烁
- 保持布局稳定

#### 局部加载
- 卡片/组件级别的加载指示器
- Spinner + 文字提示
- 半透明遮罩

#### 数据加载
```typescript
// 三种状态
- loading: 显示 Spinner
- success: 显示数据
- error: 显示错误提示 + 重试按钮
```

### 2. 反馈机制

#### Toast 通知
- 成功：绿色，3秒自动消失
- 错误：红色，5秒自动消失
- 警告：黄色，4秒自动消失
- 信息：蓝色，3秒自动消失

#### 确认对话框
- 重要操作前确认
- 清晰的主次按钮
- 支持键盘操作（Enter/Esc）

#### 表单验证
- 实时验证（失焦时）
- 错误提示在输入框下方
- 红色边框标识错误字段

### 3. 动画效果

#### 页面过渡
```css
/* 淡入淡出 */
.fade-enter {
  opacity: 0;
}
.fade-enter-active {
  opacity: 1;
  transition: opacity 200ms ease-in;
}
```

#### 列表动画
- 新增项：从顶部滑入
- 删除项：向右滑出并淡出
- 重排：平滑移动

#### 图表动画
- 初次加载：从0开始绘制
- 数据更新：平滑过渡
- 持续时间：500-800ms

### 4. 手势支持（移动端）

- **滑动** - 切换 Tab、翻页
- **捏合** - 缩放图表
- **双击** - 重置图表缩放
- **长按** - 显示详细信息

## 响应式设计

### 断点定义
```css
/* Mobile */
@media (max-width: 639px) { }

/* Tablet */
@media (min-width: 640px) and (max-width: 1023px) { }

/* Desktop */
@media (min-width: 1024px) { }
```

### 布局适配

#### Mobile (< 640px)
- 隐藏侧边栏，使用底部导航
- 单列布局
- 卡片全宽显示
- 简化图表细节

#### Tablet (640px - 1024px)
- 可折叠侧边栏
- 2列网格布局
- 适中的图表尺寸

#### Desktop (> 1024px)
- 固定侧边栏
- 3-4列网格布局
- 完整图表功能

## 可访问性（A11y）

### 键盘导航
- Tab键顺序合理
- 焦点样式清晰
- 快捷键支持

### 屏幕阅读器
- 语义化HTML标签
- ARIA标签完整
- alt文字描述

### 色彩对比
- 符合WCAG AA标准
- 对比度 > 4.5:1（正文）
- 对比度 > 3:1（大文本）

### 字体大小
- 最小字号：14px
- 可放大到200%不破坏布局
- 相对单位（rem/em）

## 性能优化

### 图片优化
- WebP格式优先
- 响应式图片（srcset）
- 懒加载
- 压缩优化

### 代码分割
```typescript
// 路由级别代码分割
```
