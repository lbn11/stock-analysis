## 🚀 如何运行

### 完整启动流程

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖（如果还没安装）
npm install
# 或
npm install --legacy-peer-deps

# 3. 启动后端（另一个终端）
cd ..
python main.py

# 4. 启动前端开发服务器
cd frontend
npm run dev

# 5. 浏览器访问
# HomePage:        http://localhost:5173/
# AnalysisPage:    http://localhost:5173/analysis/000001
# PredictionPage:  http://localhost:5173/prediction?horizon=medium
# FactorsPage:     http://localhost:5173/factors
# HistoryPage:     http://localhost:5173/history
```
